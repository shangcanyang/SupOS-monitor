邮件指令（回复邮件控制报警）

开启后，程序会用 IMAP 每 60 秒检查一次收件箱。
回复标题含 SupOS-monitor 的邮件，正文包含下列关键字即触发指令：
· 关闭 / 停用 / 停止 / 静音 / 暂停 / stop / mute / disable → 停发报警邮件
· 开启 / 启动 / 启用 / 恢复 / start / unmute / enable → 恢复发邮件
需要与 SMTP 相同的 QQ 邮箱授权码
